# Python Lists

A list is an ordered and mutable collection in Python that allows duplicate elements.

## What is inside?
- Creating a list
- Checking data type with `type()`
- Accessing elements via indexing
- List methods: `append()`, `insert()`, `pop()`, `remove()`, `sort()`
- List comprehension
- Nested lists

## Example
```python
# Creating an empty list
lst = []
print(type(lst))  # Output: <class 'list'>

# List with values
names = ["j", "h", "t", "i", "l"]
print(names)
