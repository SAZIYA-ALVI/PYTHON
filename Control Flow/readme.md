# Python Control Flow

This folder contains Python programs and examples for understanding **Control Flow** in Python.

## Topics Covered

* Conditional Statements
* `if` Statement
* `if-else` Statement
* `if-elif-else` Statement
* Nested `if`
* Decision Making
* Basic Condition Checking

## File

* `cond_state.ipynb` — Contains examples and practice programs based on Python conditional statements.

## Example

```python
age = 18

if age >= 18:
    print("You are eligible")
else:
    print("You are not eligible")
```

## Purpose

The purpose of this folder is to practice **decision-making and conditional logic in Python** and build a strong foundation for programming.
