## 📌 What is a Set?

A **set** is a collection of unique elements in Python. It does not allow duplicate values.

Example:

```python
numbers = {1, 2, 3, 3, 4}

print(numbers)
```

Output:

```text
{1, 2, 3, 4}
```

## 🔹 Important Set Methods

| Method                   | Purpose                                          |
| ------------------------ | ------------------------------------------------ |
| `add()`                  | Add one element                                  |
| `update()`               | Add multiple elements                            |
| `remove()`               | Remove an element                                |
| `discard()`              | Remove an element without error                  |
| `pop()`                  | Remove an arbitrary element                      |
| `clear()`                | Remove all elements                              |
| `union()`                | Combine two sets                                 |
| `intersection()`         | Find common elements                             |
| `difference()`           | Find elements present in one set but not another |
| `symmetric_difference()` | Find elements that are not common                |

## 🔹 Example

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print("Union:", A | B)
print("Intersection:", A & B)
print("Difference:", A - B)
print("Symmetric Difference:", A ^ B)
```
