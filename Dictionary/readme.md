# Python Dictionary

This folder contains my Python practice and learning work on **Dictionaries**.

A Python dictionary stores data in **key-value pairs**. It is useful when we want to store and access data using a unique key instead of an index. Python dictionaries are mutable and support useful methods such as `keys()`, `values()`, `items()`, `get()`, `update()`, and `pop()`.

## 📚 Topics Covered

* Creating a Dictionary
* Accessing Dictionary Elements
* Adding Key-Value Pairs
* Updating Values
* Removing Elements
* Dictionary Keys and Values
* `keys()` method
* `values()` method
* `items()` method
* `get()` method
* `update()` method
* `pop()` method
* Checking if a Key Exists
* Looping Through a Dictionary
* Nested Dictionaries
* Dictionary Comprehension

## 📝 Example

```python
student = {
    "name": "Saziya",
    "age": 22,
    "course": "MCA"
}

print(student["name"])
print(student.keys())
print(student.values())
```

### Output

```text
Saziya
dict_keys(['name', 'age', 'course'])
dict_values(['Saziya', 22, 'MCA'])
```
